Крестики-нолики Арена

Терминальная игра в крестики-нолики на Go с цветным интерфейсом, двумя режимами игры (человек против человека и человек против компьютера), простым компьютерным ИИ на основе правил и настройкой через флаги командной строки.

Как запустить

Требуется установленный Go (версия 1.22 или выше).

Клонировать репозиторий и запустить из корня:

go run . --players

или против компьютера:

go run . --ai
Доступные флаги
Usage: go run main.go (--players | --ai) [options]

Modes (exactly one required):
  --players        два игрока-человека ходят по очереди
  --ai             игра против компьютера (вы всегда X)

Options:
  --color          цветной вывод (по умолчанию: обычный текст)
  --big            отображение поля крупными символами
  --verbose        расширенная статистика
  --first X|O      кто ходит первым (по умолчанию: X)
  --name A,B       свои имена: X=A, O=B (например --name Alice,Bob)
  --size N         поле N×N, победа = N в ряд (по умолчанию: 3)
  --help, -h       показать справку и выйти

Ровно один из --players/--ai обязателен. Флаг --ai нельзя сочетать с --size — ИИ рассчитан только на поле 3×3.

Правила

Режимы игры

--players — два человека играют по очереди за одним компьютером.
--ai — игрок всегда X, компьютер всегда O (если не изменить первый ход флагом --first).

Победа и ничья

Клетки нумеруются от 1 до N² слева направо, сверху вниз.
Победа — три (или N, если задан --size) одинаковых символа подряд в ряду, столбце или по диагонали.
Ничья — поле заполнено полностью, и ни одна линия не завершена.

Как ходит ИИ

ИИ не использует перебор вариантов (минимакс) — он основан на простой лестнице правил и всегда выбирает первое подходящее:

Победа — если можно завершить линию прямо сейчас, сделать этот ход.
Блок — иначе, если игрок может выиграть следующим ходом, занять эту клетку.
Центр — иначе, если клетка 5 свободна, занять её.
Угол — иначе занять первый свободный угол в порядке 1, 3, 7, 9.
Сторона — иначе занять первую свободную боковую клетку в порядке 2, 4, 6, 8.

Логика детерминирована: при одинаковых условиях ИИ всегда делает один и тот же ход.
